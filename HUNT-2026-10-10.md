## Findings

### 1. `warmGroundFloor` contending calls (silent drop → queue)

| | |
|---|---|
| **Finding** | While one ellipsoidal floor batch was in flight, a second `warmGroundFloor` poll used to return without scheduling its cells (`src/services/groundFloor.js`, Round 6 comment). Flights (30 s) and military (15 s) could lose polls for minutes at a new airport. |
| **Fix** | Already fixed in production: contending cells go to `_pendingFloorCells` and flush in `_resolveFloorCells` `finally`. Round 1 hardens regression coverage (deterministic wait, reject path). |
| **Test** | `src/services/groundFloor.warm.test.mjs` — contending `warmGroundFloor` mid-flight schedules a second batch; queued cells still run when the in-flight batch rejects. |

### 2. Terrain chunk: one omitted height geoid-poisoned batch-mates

| | |
|---|---|
| **Finding** | `fetchChunk` in `src/services/terrainHeights.js` threw on any non-finite `ellipsoid` in an otherwise-OK proxy response. That sent the whole chunk through the geoid-fallback path, so neighbors with real Re:Earth heights were cached as `geoid-fallback` (sea-level poison) instead of `reearth` — the opposite of round 6’s intent for omitted slots. |
| **Fix** | Skip non-finite slots when building the chunk map; only true transport/shape failures use geoid fallback for the chunk. Omitted coordinates stay uncached and return `source: 'unresolved'` until a later warm succeeds. |
| **Test** | `src/data/terrainHeights.test.mjs` — mixed two-point chunk (finite + `null`) caches only the good cell; a follow-up call re-fetches the omitted point without re-poisoning the neighbor. |

### 6. AIS HTTP failures left stale `transportStatus`

| | |
|---|---|
| **Finding** | `createAisStreamSource` threw on `!response.ok` without attaching the JSON `status` (and optional `nextAttemptAt`) to the error. The ingestion catch updated `feed.error` only, so cached vessels could still show `transportStatus: 'live'` after a `503 missing-key` while the chip/error path was honest (`src/sources/live/standalone.js`, `src/layers/vessels/ingestion.js`). |

| **Test** | `src/sources/live/contract.test.mjs` — 503 missing-key rejection carries `aisTransportStatus`. `src/data/aisLiveVessels.test.mjs` — after a prior `live` poll, HTTP 503 updates `transportStatus` to `missing-key` while cached count stays nonzero. |
